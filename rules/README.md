# WSDC rules archive

Every known version of the World Swing Dance Council (WSDC) rules, from the first
Points Registry of 2002 to the current drafts – as searchable, comparable HTML,
together with the original PDFs.

- **Read and compare online:** worldsdc.com/rules/archive/ (WordPress plugin `goo1-wsdc`, shortcode `[wsdc_rules]`)
- **Board tools** (timeline, history of a rule, draft review, search, statistics): manage.worldsdc.com/en-us/rules
- **Locally:** open `rules/index.html` through any web server (`python3 -m http.server` in the repository root, then `/rules/`)

## What is in here

| Path | Content |
|---|---|
| `versions.json` | One entry per version: document type, version, effective and published dates, status (final, draft, missing, translation, variant), source URL, SHA-256 of the PDF, predecessor. `current` names the version in force. |
| `html/<id>.html` | The rules text as an HTML fragment. Format: [`tools/HTML-SPEC.md`](tools/HTML-SPEC.md). The WSDC's own yellow/green change highlights are kept as `<mark>` / `<mark class="green">`. |
| `pdf/<id>.pdf` | The original PDFs, named by the version printed in the document (not by the original file name, which is often wrong). |
| `img/` | Images used by the HTML (advancement chart arrows). |
| `data/` | Generated by `tools/build.py`: rule units per version, changes to the predecessor, mapping of rules across versions, rule histories (lineages), statistics, search index. |
| `viewer/` | Plain JavaScript/CSS viewer with version switch, highlight toggle and word-level comparison of any two versions. Used by worldsdc.com and manage.worldsdc.com. |
| `tools/` | `extract.py` (PDF → text with highlight markers and page images), `check.py` (checks an HTML file against its PDF), `build.py` (derived data). |

## Document history in short

- **2002–2015:** a short "Points Registry" document, from 2007 also separate "Registry Event Requirements".
- **2018–2020:** two documents, *Points Registry Rules* (RPR) and *Registry Event Rules* (RER), versions like `2019.1A`.
- **May 2021:** addendum (non-dominant role, lower competitor requirements).
- **Since 2023.1B:** one combined document *Registry Event Rules*.
- **Drafts** are included where they were published (2024, 2025, 2026, 2027.V.3, 2027.V.4).

Known but not (yet) found: Registry Event Requirements of 11/2007, 01/2009, 01/2010, 09/2010 and 01/2012, and the 2027 drafts V.1 and V.2.
If you have one of these, please open an issue.

## Adding a new version

1. Put the PDF into `pdf/<id>.pdf` and add an entry to `versions.json`.
2. `python3 rules/tools/extract.py rules/pdf/<id>.pdf /tmp/extract/<id>` – text with `[[Y:…]]`/`[[G:…]]` highlight markers and page images.
3. Copy the HTML of the predecessor to `html/<id>.html` and apply the differences (this keeps the rule IDs stable).
4. `python3 rules/tools/check.py rules/html/<id>.html` until it reports `OK`, and compare the tables with the page images.
5. `python3 rules/tools/build.py` – updates `versions.json`, `data/` and the copy of the version in force in `/registry_event_rules.html`.
6. Commit and push. worldsdc.com and manage.worldsdc.com pick the new version up within a few hours (or at once with "Reload from GitHub" in manage).

## Sources and thanks

Most PDFs come from worldsdc.com (many have since been removed there), from the
Wayback Machine (web.archive.org, including the old site swingdancecouncil.com),
and from the rules archive collected by Denis Balakin for
[wsdc-analytics](https://wsdc-analytics.github.io/rules_catalog_en.html).
The source of every file is recorded in `versions.json`.

The texts are documents of the World Swing Dance Council. The HTML conversion keeps
the original wording, including typos.
